## Overview

A simple Windows network diagnostics and repair toolkit built with Batch.

## Features

- Network diagnostics
- Ping & traceroute
- DNS tools
- IP release & renewal
- Winsock & TCP/IP reset
- Wi-Fi tools
- Basic network scan

## Usage

Run `WinFix-Network-Toolkit.bat` as **Administrator**.

## Requirements

Windows 10 / 11
